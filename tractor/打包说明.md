## 一、成品在哪

打好包之后，APK 在：

```
I:\CrazyMonkey14\tractor\app\拖拉机.apk
```

把这个文件传到妈妈的手机上装就行了。

## 二、怎么装到手机上

1. 把 `拖拉机.apk` 用微信/数据线/网盘传到手机。
2. 在手机上点这个文件，会问「是否允许安装未知应用」——**允许**。
   - 如果找不到这个开关：`设置 → 应用 → 特殊应用权限 → 安装未知应用 → 找到你用来打开文件的程序（比如「文件管理」或「微信」）→ 允许`。
3. 装好后，桌面上会出现一个**绿底金圈、中间一只猫脸**的图标，名字叫「拖拉机」。
4. 点开就能玩。**打开时是横屏**，把手机横过来拿。

> 妈妈的手机是 vivo，第一次装可能会弹「该应用未经安全检测」之类的提示，选**继续安装**就行。
> 因为这个包没有花钱做签名认证，属于正常现象。

## 三、改完游戏想重新打包

改完 `I:\CrazyMonkey14\tractor\` 里的网页版（`js/`、`style.css`、`index.html`），
然后**双击**：

```
I:\CrazyMonkey14\一键运行.bat      ← 平时用这个
I:\CrazyMonkey14\tractor\app\build-apk.bat  ← 只打包，不装模拟器
```

黑窗口会自己跑完，最后打出新的 `拖拉机.apk`。**第一次跑比较慢**（要下依赖），之后快很多。

`一键运行.bat` 比 `build-apk.bat` 多干三件事：连模拟器、装进去、自动打开。
**用之前先把雷电 9 打开**，别的不用管。四步走完模拟器上就直接是新版本了。

## 三之二、在电脑上先试玩（雷电模拟器）

装了**雷电 9**，位置：`I:\LDPlayer9\`（不在 C 盘）。

用它之前要设一下分辨率，让模拟器跟妈妈手机一样大：

1. 打开雷电 9 → 右边工具栏「设置」（齿轮图标）
2. 找**性能设置 / 分辨率**那一栏
3. 分辨率填 **3168 × 1440**，DPI 填 **560**
4. 保存，重启模拟器

> 这是 vivo X500 Pro Max 的屏幕参数（6.85 英寸）。
> 如果嫌窗口太大占屏幕，改成 **1810 × 822 + DPI 320** 也一样是同样的长宽比，
> 界面布局完全一致，只是窗口小一圈。

设好之后，每次就一句话：**开雷电 → 双击 `一键运行.bat` → 玩**。

## 五、编译工具链（已装好，都在 I 盘）

这台电脑上原本没有 Java 和安卓 SDK，已经装好了。
**所有东西都在 `I:\CrazyMonkey14\.toolchain\` 里，C 盘一点没占**：

| 目录 | 大小 | 是什么 |
| --- | --- | --- |
| `.toolchain\jdk-21.0.12.1+1\` | 329 MB | Java 21（绿色版，解压即用） |
| `.toolchain\android-sdk\` | 577 MB | 安卓 SDK（android-36 / build-tools 36.0.0） |
| `.toolchain\gradle-home\` | 1003 MB | 编译依赖缓存（**会随打包次数增长**） |

`build-apk.bat` 里已经设好了 `JAVA_HOME`、`ANDROID_HOME`、`GRADLE_USER_HOME`
三个变量指向这些目录，所以双击它不会往 C 盘写任何东西。
**没改系统环境变量，也没改系统设置**，删掉 `.toolchain` 就等于彻底卸载。

编译参数（`tractor\app\android\variables.gradle`）：最低支持安卓 7.0（API 24），目标 API 36。
妈妈的 vivo 手机肯定够。

### 三个踩过的坑（换电脑重装时照做）

1. **`winget install Temurin` 装不上** —— 后台一直没反应，别浪费时间。
   直接从 `https://api.adoptium.net/v3/binary/latest/21/ga/windows/x64/jdk/hotspot/normal/eclipse`
   下绿色压缩包解压，效果一样。
2. **`android\local.properties` 里反斜杠必须写两个**。写成 `sdk.dir=I:\Crazy...`
   的话 Java 会把 `\C` 当转义符吃掉，Gradle 报「文件名、目录名或卷标语法不正确」，
   而且报错点看不出是路径问题。工程里 `fix-sdk-path.py` 会自动写对，
   `build-apk.bat` 每次打包前也会先跑一遍。
3. **在 Git Bash 里调 robocopy 要给 `/E` 这类参数加 `MSYS_NO_PATHCONV=1`**，
   否则 MSYS 会把 `/E` 当成 `E:\` 路径传过去，命令直接报参数无效。
4. **批处理里必须写 `.\gradlew.bat`，不能只写 `gradlew.bat`。**
   这台机器设了 `NoDefaultCurrentDirectoryInExePath=1`，cmd 不肯在当前目录下找程序，
   裸名字会报「不是内部或外部命令」。`make-build-bat.py` 里已经写对了。
5. **`.bat` 文件必须是 GBK 编码 + CRLF 行尾。** 存成 UTF-8 或 LF 的话，
   cmd 会把中文注释拆成乱码命令、把 `if (...)` 括号块解析错乱，
   表现是一堆莫名其妙的「不是内部或外部命令」。所以别手改 `build-apk.bat`，
   要改就改 `make-build-bat.py` 然后 `python make-build-bat.py` 重新生成。

  应用名是「拖拉机」、锁定横屏、最低支持安卓 7.0。
- ✅ 已确认：**在雷电模拟器上（3168×1440，跟妈妈手机一样）装起来跑过**，
  发牌、叫主、扣底、出牌、结算都能走通，截图看过版面。
- ✅ 已确认：**牌桌上出的牌跟手牌一样大**（46×67，原来是 30×43）。
  做法是把对家的头像从牌桌顶上挪到**牌桌上方中间偏左浮着**（不占地方）、
  左右两家贴到牌桌外沿——腾出来的地方全给出牌区。出的牌上**不再写名字**，
  靠方位认人（上=对家、左=上家、右=下家、下=自己），只有最大那家挂一块「最大」金牌子。
  对家甩的牌特别多（≥6 张）时整手挪到右边那列摆，别挤着左上角。
- ✅ 已确认：**牌面点数放大**（52px 的牌上从 18px 变成 26px），手牌和牌桌上的牌都变醒目了。
- ❌ 没确认：**你的真手机上**。模拟器毕竟不是真机，真机上如果发现哪里
  显示不对（字太小、牌被挡住、按钮点不准之类），截图告诉我我来调。

## 七、以后想换头像

`tractor\js\ui.js` 开头有个 `AVATARS`：

```js
const AVATARS = {
  '墩布': 'assets/cat-joker.jpg',
  // '李淑静': 'assets/avatar-lishujing.jpg',
};
```

把妈妈的、或者其他人的头像图片放进 `tractor\assets\`，然后按这个格式加一行，
名字必须和 `tractor\js\game.js` 里 `PLAYER_POOL` 的名字**一模一样**。
没配头像的人会自动用名字第一个字当头像，所以配一个也行，全不配也能跑。
改完重新打包一次即可。
